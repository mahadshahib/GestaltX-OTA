# GestaltX OTA

Personal re-signing of [GestaltX v1.0.6](https://github.com/huamidev/GestaltX/releases/tag/v1.0.6), using Urvashi Sampath’s team. The app and share extension use a dedicated common registered App Group.

Install: https://mahadshahib.github.io/GestaltX-OTA/

Only registered devices can install. Application code is unchanged; bundle identifiers and signing entitlements are adapted to the signing team. Source code, GPL-3.0 license and third-party notices are included.
