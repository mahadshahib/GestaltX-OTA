Install GestaltX

Only the 19 devices registered in the signing profiles can install this build. Enable Developer Mode if requested. If iOS asks you to trust the developer, use Settings → General → VPN & Device Management.

The app and its share extension are both included and signed with the shared App Group group.com.mahadshahib.gestaltx.

On-device MobileGestalt editing requires iOS / iPadOS 27.x; iOS 26.x does not support that access. Back up your device before changing MobileGestalt. Incorrect changes can cause instability or require a device restore.
